# Ssemanda Owen — Kilo Code Skills Pack

This pack contains 12 custom Agent Skills for Kilo Code, focused on Node.js, PostgreSQL, Redis, APIs, trading systems, ML, debugging, security, testing, performance, architecture, and professional UI.

## Install globally on Windows
Copy the `.kilo/skills` directory contents into:

`%USERPROFILE%\.kilo\skills`

## Install for one project
Copy `.kilo/skills` into the project root.

## Reload
Start a new Kilo session or use `/reload` after adding or changing skills.

Each skill has a `SKILL.md` with Kilo-compatible YAML frontmatter and detailed instructions.
