# AGENTS.md — corex-accounts

Package: `corex-accounts` — Account identity, connection credential management.

## Conventions
- Node.js >= 18. CommonJS modules (`require`/`module.exports`).
- Tests: `npm test` runs `jest --passWithNoTests --testTimeout=20000`. All specs in `test/**/*.test.js`.
- Path aliases via `moduleNameMapper` in `package.json` jest config: `@root`, `@core`, `@utils`, `@events`, `@config`.

## Architecture
- **Pure-logic package** (for services) + **DB-coupled** (via direct `pg` pool).
- Accounts: `cx_pap_<ulid>` / `cx_liv_<ulid>` identity management.
- Connections: Credentials encrypted with same AES scheme as `connectorSettingsService.js`.
- **Constraint:** Unique (account_id, connector_type).

## Boundaries
- Do not bypass `connectionsService` to manipulate `connections` table directly.
- Credentials must be encrypted *before* save, decrypted *after* read.
- `accountId` is generated by caller (using `corex-gateway` conventions), not this package.

## Human verification required
- Multi-account connectivity: Verify two MT5 connectors with different account IDs do not overwrite each other.
- Revocation: Verify `revokeConnection` disables connection status.
